原稿サイズチェッカー

Google Drive上の画像(TIFF/JPEG)の寸法(px)・DPI・カラーモード・拡張子を、取引先ごとのマスタ設定と照合します(幅・高さは以上/ちょうど/以下で判定可)。すべてブラウザ内で完結し、サーバーへのアップロードは行いません。

ログイン

ログインすると、取引先ごとの原稿仕様(サイズ・DPI・カラーモードなど)に沿って、Google Drive上の画像をまとめてチェックできます。
ご利用にはGoogleアカウントでのログインが必要です。事前に登録されたアカウントのみ利用できます。
初めて使う方はこちら(アクセス申請)

Googleログインには事前登録が必要です。お名前とご自身のGmailアドレスを入力して送信すると、担当者に通知が届きます。追加され次第使えるようになります。

ツールの追加機能・変更点はここでお知らせします。更新があると、ログイン後にこの画面が最初に開きます。
初回セットアップ手順(Google Cloud OAuthクライアントIDの取得方法)
  1. Google Cloud Console にアクセスし、新しいプロジェクトを作成(既存プロジェクトでも可)。
  2. 左メニュー「APIとサービス」→「ライブラリ」で Google Drive API と Google Sheets API を検索し、それぞれ「有効にする」。
  3. 「APIとサービス」→「OAuth同意画面」で、User Type を選択(社内のみなら「内部」、それ以外は「外部」)し、アプリ名・サポートメール等を入力して保存。テストユーザーを使う場合は利用する社員のメールアドレスを追加。
  4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」を選択。アプリケーションの種類は「ウェブアプリケーション」。
  5. 「承認済みのJavaScript生成元」に、このHTMLファイルを実際に開くURL(例: https://your-team.github.io や社内サーバーのURL)を追加して保存。ローカルで file:// のまま開くと動作しません。GitHub Pages、Google Sites、社内Webサーバーなど、httpsで配信できる場所にこのファイルを置いてください。
  6. 発行された「クライアントID」をコピーし、下の「設定」欄に貼り付けて保存。
  7. マスタ用のGoogleスプレッドシートを1つ用意し、1行目に 取引先名 / 幅px / 高さpx / DPI / カラーモード / 幅判定 / 高さ判定 / 拡張子 の見出しを入れておく(なければツール側の保存操作時に自動で追加されます)。そのスプレッドシートのURLを「設定」欄に貼り付けて保存。
  8. 「設定」欄で保存したら「Googleでログイン」ボタンからアクセス許可(Drive閲覧・Sheets編集)を承認してください。

設定 通常は変更不要

クライアントIDとマスタシートはあらかじめ設定済みです。別のプロジェクト/シートに切り替えたいときだけここを変更してください。

取引先マスタ管理

数値を空欄にした項目はチェックしません(例: 高さを空欄にすると高さは不問)。幅・高さは「以上/ちょうど/以下」で判定できます。

📘 はじめての方へ ・ 使い方(3ステップ)
  1. 取引先を選ぶ … 下の「① 取引先を選択」で選ぶと、その取引先の判定条件(サイズ・DPI・カラーモード・拡張子)が自動で入ります。
  2. チェックしたいGoogle Driveのフォルダを貼り付ける … Driveでフォルダを開いたときのURLをそのままコピーして貼り付けます。複数フォルダは改行で追加できます。中のサブフォルダもまとめて調べたいときは、下の「サブフォルダも含めてチェックする」にチェックを入れてください。
  3. 「チェック開始」を押す … 各画像の寸法(px)・DPI・カラーモード・拡張子を条件と照合し、OK / NG を一覧で表示します。結果は「CSVでダウンロード」で保存できます。

🔎 一覧の上に「ファイルセット整合性チェック」も表示します。ファイル名末尾の番号をもとに、ページの重複(古いファイルの消し忘れ)・連番の欠番・ファイル数と最大番号のずれを検出します。psd フォルダも一緒に貼り付けると、psd と画像でページが揃っているかも突き合わせます(1案件ずつ実行してください)。

💡 画像はあなたのブラウザ内だけで読み込まれ、どこかへアップロードされることはありません。取引先の条件を追加・変更したいときは、上の「取引先マスタ管理」タブから行えます。
